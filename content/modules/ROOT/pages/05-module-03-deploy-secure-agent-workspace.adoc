== Deployment scope

The raw harness and SAW deployment are separate environments. This installation
adds a KubeVirt VM for the configured workspace owner, an OpenShell gateway and
container runtime inside that VM, Keycloak OIDC, Vault and External Secrets, a
governance interceptor, and GitOps-managed configuration.

Use a dedicated workshop cluster. The pattern installs cluster-scoped operators
and OpenShift Virtualization resources; its uninstall path can affect other
virtualization workloads.

== Learning objectives

* Select a supported control node and verify OpenShift Virtualization capacity.
* Prepare SAW SSH keys and provider secret values without committing credentials.
* Mirror the required images and install the Validated Pattern.
* Identify the installation stop condition and collect failure diagnostics.

== Installation stop condition

Do not continue until the setup Job is `Complete` and the VM instance is
`Running`:

[source,bash,role="execute",subs="attributes+"]
----
oc -n {saw_namespace} wait --for=condition=complete \
  job/{saw_gateway_name}-setup --timeout=5400s
test "$(oc -n {saw_namespace} get vmi {saw_gateway_name} \
  -o jsonpath='{.status.phase}')" = "Running"
----
